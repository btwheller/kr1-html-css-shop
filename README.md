# Учебный frontend-проект: каталог услуг

## Описание

Репозиторий создан в рамках дисциплины «Фронтенд и бэкенд разработка».

Тема проекта: многостраничный сайт каталога услуг.

## Структура проекта

- `index.html` — стартовая страница;
- `css/style.css` — таблица стилей;
- `images/` — каталог для изображений;
- `.gitignore` — файлы, исключённые из версионного контроля;
- `README.md` — описание репозитория.

## Используемые технологии

- HTML;
- CSS;
- Git;
- GitHub.
